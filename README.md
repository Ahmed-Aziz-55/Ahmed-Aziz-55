## 🚀 Featured Projects

### 🔎 VisionSeek — Visual Search Engine

A visual search system built using **CLIP embeddings and FAISS** for image retrieval.

* CLIP-based image and text embeddings
* FAISS similarity search
* ~159K indexed records
* Recall@1: ~49.8%
* Recall@5: ~73.3%
* Recall@10: ~80.9%
* Fast similarity search API
* FastAPI backend

### 🖼️ Image Quality Assessment

A Computer Vision system designed to determine whether an image is suitable for downstream CV tasks.

Includes detection for:

* Blur
* Darkness
* Glare
* Overexposure
* Motion artifacts
* Occlusion
* Poor framing
* Low resolution

Uses **Computer Vision heuristics, ONNX models and Machine Learning-based suitability classification**.

### 📄 Local Invoice Processing System

A local invoice-processing pipeline focused on extracting structured invoice information without using an LLM during inference.

Pipeline includes:

* OCR
* Invoice text processing
* Line-item extraction
* Quantity extraction
* Unit-price extraction
* Tax extraction
* Line-total extraction
* Total validation
* Structured JSON output
